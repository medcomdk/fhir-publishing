# fhir-publishing

Publishing helpers and workflows for FHIR implementation guides.

For local development, the [MedCom Firely Validation VS Code extension](vscode-extension/README.md)
runs the Firely setup, SUSHI build, and resource validation workflow directly from the editor.

Extension contributors can find build, test, and packaging instructions in the
[extension development guide](vscode-extension/DEVELOPMENT.md).
